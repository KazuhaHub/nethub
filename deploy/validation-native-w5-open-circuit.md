# Native public Open and local circuit validation

Unsigned 0.0.17 passed installation, fresh enrollment, public console Open and
the local circuit switch on the native OPNsense appliance. The backend used the
accepted images from source `a69fa27`, run `40145347040`; the package came from
`77ddab2`. The approved 1 GiB allocation remains a resource deviation.

A fresh public TLS connection was refused before Open. A real console button click
then created one grant and opened a tab with its opener severed. Node and Chrome
verified the issued leaf with normal DNS and system trust, without TLS exceptions.
The browser logged into OPNsense and received 29 successful Dashboard API responses.
This was a desktop public-network test; it does not replace the W5 mobile sample.

The independent local GUI used an exact certificate pin for its loopback address.
Its actual checkbox stopped frpc and refused a fresh public TLS connection. Native
samples across 73.610 seconds found the service stopped and the marker retained.
The complete `config.xml`, saved enabled intent and GUI private key stayed unchanged
through both switch operations. After release, a fresh system-trusted public TLS
connection succeeded. The sample does not cover an entire five-minute watchdog cycle.

The public certificate used the existing registered account and genuine native
cron application. Read-only inspection confirmed one issued job, a valid saved
order, retired HTTP-01 proof, and unchanged first generation/application records.
Normal native UI removal cleared enrollment, rendered revocation in the console
and refused the old TLS route while the public listener remained available.

Live positive controls reached the configured internal callback, admin and control
listeners. From Windows over the public network, control TCP was reachable while
the callback, admin and private origin ports were refused. No source-IP fixture
compensation was used. The independent-access reminder was visible before enrollment.

Independent checks verified exported material, the original native trust and
restart script, the original package/configuration/stopped intent, and restoration
of all fourteen original server containers and listener owners. Earlier attempts
stopped before enrollment at an owned-network preflight and an incorrectly addressed
admin probe; their failed outcomes were retained separately.

Native authz-outage timing, console Revoke/no reconnect, reboot, configuration
restore, WAN changes and the mobile Open flow remain open. This is partial W5
acceptance, not a signed release or complete W5 acceptance.
